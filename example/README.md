# ona_bottom_sheet example

A tour of every sheet the package draws: a long list, a confirmation, a form above the keyboard, an always-on sheet
and a custom theme, in light and dark.

    flutter run                                  # the tour
    flutter run --dart-define=ONA_TOUR=true      # walks the demos by itself
    flutter run --profile -t lib/bench.dart      # frame times on a device
